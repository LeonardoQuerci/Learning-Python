## 📁 Projetos

### ✅ Projeto 01 — Gerenciador de Contatos CLI
> Fase 1 — Python Essencial

Aplicação de terminal para gerenciar contatos salvos em arquivo JSON.

**O que foi praticado:**
- Leitura e escrita de arquivos JSON
- Organização de código em funções com responsabilidade única
- Manipulação de listas e dicionários
- Controle de fluxo com menus interativos
- Validação de dados (email duplicado, confirmação antes de remover)

**Como rodar:**
```bash
cd Gerenciador-de-Contatos
python index.py
```
