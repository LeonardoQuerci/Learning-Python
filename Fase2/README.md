# Sistema Bancário CLI

Projeto desenvolvido para praticar orientação a objetos em Python.

## Funcionalidades
- Criar conta corrente ou poupança
- Depositar, sacar e transferir entre contas
- Ver extrato de movimentações
- Aplicar rendimento em contas poupança
- Dados persistidos em JSON entre execuções
- Tratamento de erros com exceções customizadas

## Como rodar
python banco.py

## O que aprendi
- Classes, herança e encapsulamento
- Exceções customizadas com hierarquia
- Serialização e desserialização de objetos para JSON
- Polimorfismo com isinstance
- Separação entre lógica de negócio e interface do usuário
